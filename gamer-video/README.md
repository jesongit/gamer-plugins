# 视频工作台

管理视频、录制操作与制作演示素材包。没有项目层，也不需要绑定配置包。

- 在已结束的录制中选择范围，提取操作前后截图和原始点击、按键等事件。查看 START/END 是可选预览，不需要填写目标或确认流程成功。
- `.gamersample` 使用格式版本 2，只包含说明、原尺寸 PNG 与原操作记录，不内嵌视频，不引用原视频作为运行依赖。原视频只在制作时用于提取截图。
- 素材独立保存在 `data/plugin-data/gamer-video/samples/<id>.gamersample`，支持导入、导出、删除。删除视频与删除素材分别处理。
- 自动化按用户教学步骤和选定素材生成脚本版本，脚本和模板存入自动化配置包。素材检查只验证图片、引用和模板匹配，完整游戏流程由实际运行验证。

服务端验证 ZIP 路径、重复文件、类型、大小、SHA-256、图片尺寸和操作帧引用。压缩与展开总量限 128 MiB，最多 240 张 PNG、100 个操作；等待时长不要求连续帧覆盖。
