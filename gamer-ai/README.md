# AI 游戏助手

`gamer-ai@0.1.1` 是 builtin 插件。需要包含本次 AI 实现的 Gamer 宿主；插件归档自身不包含 Rust 执行体。用户在工作台输入自然语言目标，所有游戏决策由已通过图片连接测试的多模态模型作出，没有按游戏或活动写的分支。

## 使用

1. 安装本地构建的 `.gplugin`，选择设备、Android 运行应用和配置包。启用和打开面板不会发起模型请求。
2. 在「模型与预算」先填 URL 和密钥，保存时只读取模型列表并选择候选模型，不发起推理；协议、模型和其他选项收在高级设置。兼容服务不提供模型列表时可手动选择协议和模型。API 没有响应费用时，须在高级设置补充合同价格及价格版本，否则首个收费测试保留预留金额并停下等待对账；未知费用不会显示为零。金额使用微美元，1,000,000 微美元 = 1 美元。Ollama 本地推理费用记零，仍受轮数、token、时长和并发限制。
3. 点击「测试图片与工具往返」。测试发送随机图片、验证坐标，再验证带宿主回执的第二轮工具结果；API 测试会产生正常请求费用。修改地址、模型、协议或密钥会清除已验证能力。原生搜索另行测试图片、搜索、函数的组合能力，配置搜索预留后才可开启。
4. 在「目标」输入目标并运行。会话展示进度、操作、关键原图和每次请求账本；输入成功不表示任务完成，完成需另抓画面并请求模型验证全部子目标。
5. 无额外消耗的独立部分继续执行。道具、货币、门票、钥匙、付费或无法判断的消耗生成对话授权卡片。核实画面后，选择「仅这次操作」或「永久授权」并确认资源、用途及总额度；也可选当前目标或已核实周期。永久规则先确认账号，允许不设到期时间，但额度累计且可随时撤销；只确认账号不要求填写周期。聊天文字不会直接批准消耗，确认卡片后重新观察并继续。
6. 「停止」取消当前运行；「人工接管」先取消、等待已接受输入收尾、释放触点和按键，再开放人工输入。观看不取消运行。接管收尾失败时仍保持输入关闭，修复设备链路后重试接管。

支持 Responses、Chat Completions 兼容 API、Claude Messages、Gemini GenerateContent 和 Ollama Chat。URL 支持服务根地址或常见完整方法路径，不接受查询参数或内嵌密码；协议自动识别有歧义时可在高级设置指定。模型列表只是候选，不证明支持图片。能力测试结果仅适用于该配置版本，协议适配器 mock 通过不等于任意供应商或本地模型实际支持。

## 对话、提问和有限试错

同一设备、同一游戏的新目标可带入私有历史中由用户确认的账号参考值，避免重复批准已有永久规则；这不表示当前画面已验证。每次额外消耗前仍通过多模态账号及资源复核，画面无法确认时先导航核实或提问，不消费。不同设备不自动带入该参考值，配置包攻略也不能提供账号授权；新目标不继承旧游戏周期。

目标页是持续对话：显示简短判断、执行计划、动作、结果和原图证据；运行中可以补充要求，尚未执行的旧模型响应失效，其实际请求费用仍保留。输入框支持 Enter 发送、Shift+Enter 换行及中文输入法。历史问题、回答和进度随逻辑会话保存。

操作前先查本地经验、必要时搜索，按入口、前置、步骤、消耗、版本和完成判据判断依据是否足够，再制定可见计划。知识仍不足时提出选项或自由回答，保存检查点并释放设备。用户回答后重新观察、制定计划，验证有效的步骤可保存为永久攻略，记录真实回答引用与适用条件；攻略本身不能替代当前画面和授权。

提问默认等待 120 秒，可设置 5～3600 秒。仅知识问题超时可尝试自主解决，默认同一逻辑会话最多自动恢复 3 次、最多执行 3 个可恢复动作；设置 `max_trials=0` 关闭。每个试错动作另经多模态画面核实，不执行整段 YAML、不使用额外道具或货币（即使存在长期授权），仍受轮数、时间、费用、重复动作和完成复核约束。账号、区服偏好、密码/验证码和授权问题超时仍等待用户；不要在聊天中输入密码或验证码，使用人工接管完成登录。到达边界保存进度并通知，不无限试错。

普通 Chat/Ollama 没有原生网页搜索。可配置外部搜索服务：`POST` 接收 `{query,max_results:5}`，返回 `{results:[{url,title,content}]}`；宿主限制条目及内容长度，来源作为不可信文本。Responses/Claude/Gemini 的原生工具组合必须通过专门测试；不支持时继续画面探索或使用外部服务。

## 方案、任务和恢复

方案在当前配置包的 `plugins/gamer-ai/plans/*.json`，格式为 `{goal,model_profile_id,resume_session_id:null}`。从面板保存后，在任务页选择 `gamer-ai`、方案或临时目标，复用现有 cron/provider 调度与后台运行。入口为 `<package>#goal` 或 `<package>/<plan>.json`，临时目标 payload 为 `{goal,model_profile_id,resume_session_id?}`。

预算模板在插件设置中；新逻辑会话冻结预算、方案和模型版本。恢复累计原逻辑会话的请求、轮数、token、活动时间及授权消费，不能用新 run 清零。需要加额度时，先修改预算设置，再对停止的会话点击「应用当前设置中的预算上限」。此操作保留已发生费用、未知预留和消费记录。方案、模型或 Package 实例变化时拒绝旧会话恢复；新建目标仍计入全局总账。

同设备、入口、目标和冻结配置的定时任务会复用待处理会话，即使仍在等待账号或周期确认，也不新建账本重置预算。周期由真实游戏信息确认，不默认本地零点。当前实现支持 Android，浏览器目标明确拒绝。

## 数据与授权

可分享攻略只放在 `plugins/gamer-ai/guides/*.json`。来源来自本次搜索实际返回的 URL；候选提案记录日期并脱敏已确认账号。攻略管理支持读取、修订和删除。分享前仍需检查自由文本。

模型、凭据、授权、账号/周期记录、失败记录、完成记录、截图和账本保存在 `data/extension-data/gamer-ai/`，不进入 Package 导出。Windows 设置凭据使用现有 DPAPI 保护；账本原子写入、损坏拒绝启动，不静默清零。本机 `verified` 依赖 Package 实例、内容哈希、资源实例和仍存在的证据。导入、复制、同字节覆盖及删除重建均不能继承信任；文件内的 `verified:true` 无效。已读候选可在本次真实执行和独立完成验证后建立本机记录。

默认只允许 navigation 和正常 regenerative_resource。其他类别需明确规则；单次绑定 operation_id，会话绑定 logical_session_id，周期/长期规则绑定已确认账号及准确资源、用途、规则版本和期限。额度在输入前预留，结果未知不释放、不重放。网页、截图、攻略和模型都不能批准规则。

## 通知与用量

通知复用可选 `gamer-notify` 和现有通道，不自动启用或配置。待授权汇总和预算阻塞分别去重；无通道时待办保留在面板。普通完成/失败按配置发送；任务对应终态规则有效时由任务 hook 发送该终态。默认等待授权或预算阻塞只发送对应摘要；明确开启的任务 failed 规则仍可能另发任务结果。partial/waiting 在通用任务表映射 failed，错误附已完成进度。未知投递不自动重试。

每次推理、搜索、YAML 副作用检查和完成验证都先原子预留，再结算。缓存读取是 input 子集，Claude 缓存写入有单独价格；没有写入价格且供应商未提供费用时保留待核对。原生工具附加费单独作为保守估算，不显示为供应商已确认。超时/取消保留未知费用，不假定退款。

可选对账支持 OpenAI 项目、Claude 工作区和 OpenRouter 专用 key 的独立凭据；账单快照与 Gamer 请求总额分开。最多查询七天，分页未完整时明确 partial，不自动关联或叠加账号总账。用户可给未知或估算请求录入供应商引用、范围和确认金额。组织 API 资格、实际权限和计价合同需在真实环境核验。

## MCP

在面板签发独立凭据，限定设备、应用、配置包、工具和最多七天有效期。token 仅签发时显示一次，磁盘只存摘要。`POST /mcp/gamer-ai` 使用 `Authorization: Bearer <独立凭据>` 的无状态 JSON-RPC HTTP；支持 initialize、ping、tools/list、tools/call。管理员 Cookie/回环 token 无效，MCP token 不能访问管理员 REST、配置、原始控制或批准接口。

控制工具为 `gamer.goal.submit/status/cancel`、`gamer.session.open/close`。goal.submit 委派受门禁约束的自主 Runner；外部工具模式先 open，随后工具带宿主签发的 session_id。observe 返回 PNG ImageContent、结构化观察身份和真实用户补充；act 由宿主多模态检查外部消耗声明；`set_plan` 提交有依据的计划，`ask_user` 在 Gamer 对话页提问。攻略检索、搜索、候选提案、授权请求、自动化发现/调用和完成复核使用同一工具层。管理员回答、批准和配置不向 MCP 凭据开放。超时自动恢复仍检查原凭据；只允许外部工具会话的凭据由原客户端继续，不会被计时器升级成管理员自主运行。YAML 与原生工具共用取消、输入所有权、逐次副作用门禁及逻辑会话账本。

工具会话空闲 60 秒、最长 15 分钟；凭据过期或撤销取消进行中的推理及操作。凭据只能访问自己签发范围内的 run/逻辑会话，不能借其他凭据恢复。管理员可在面板显式接管恢复，额度保留。外部客户端模型自身账单不属于 Gamer 账本。

## 验证和发行

`./gamer-ai/build.ps1` 走现有固定 SDK 打包入口，builtin 无 guest。宿主集成测试以 mock 模型、搜索、设备和时钟验证正式业务路径；协议测试使用 loopback HTTP，不发送收费请求。新宿主机制需要与本插件一起发布，固定 SDK 来源提交和主仓 gitlink，不跟随远端最新提交。尚未更新已公开首装插件发行锁。

模型可能漏判消耗、完成状态或账号；新图复核和门禁不能提供绝对语义保证。供应商原生搜索上界、网络延迟、取消后的计费和账号级账单延迟仍有外部不确定性。跨游戏成功率、误判、真实费用及设备操作尚待真实验收，步骤与当前证据见主仓 `docs/reports/gamer_ai_validation_2026-10-01.md`。
