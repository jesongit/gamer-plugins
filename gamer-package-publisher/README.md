# 配置包发布

需要 Gamer 0.2.1 或更高版本（resource Host API 1.1）。这是 builtin 插件：界面独立分发，受限的 GitHub CLI 适配随宿主编译。

在运行 Gamer 的电脑上安装 GitHub CLI，执行 `gh auth login --hostname github.com` 登录。发布账号需要目标公开仓库的写权限。插件不会把令牌传给浏览器，也不提供任意 shell 命令入口。

在工作台打开“配置包发布”，检查登录、选择本地配置、填写仓库与说明，生成预览。已有导出文件可先在“配置包”页导入。点击创建草稿，检查完整清单后点击“公开发布”。发布过程中可取消；远端草稿保留，通过“恢复发布任务”继续。未安装此插件的用户仍可订阅和下载配置。

每次发布完整目录，未选中的已有配置会保留。同 ID/版本的内容改变时必须先提升配置包版本；不允许降级发布。草稿重试不会覆盖不同内容的同名文件。预览后本地修改不会改变已冻结归档。

首次使用的 GitHub 仓库需先有初始提交（例如 README）。仅支持 github.com 公开仓库。发布前复核最新目录，若发现其他作者已更新则要求重新准备；多个作者应协调避免同时发布。

归档与任务记录保存在应用数据目录的 `package-publisher/jobs/`，不进入配置包导出。下载和仓库源配置独立于本插件。取消有界等待正在进行的下载或归档操作，gh 子进程最多执行 120 秒。

权限 `package.publish` 允许导出所选本地配置并使用宿主 gh 账号管理目标仓库的发布草稿和公开状态。安装/启用插件即向该插件授予此能力，公开操作还需界面确认。
